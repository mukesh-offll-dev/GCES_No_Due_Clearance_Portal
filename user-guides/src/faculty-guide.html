Step 1

Student Directory and adding students

Log in with Institution Login → Office Faculty Advisor (details from the administrator). Choose a Branch and Year to open a class.

Add one student

  1. Open the class → Add Student.
  2. Enter the 12-digit Register Number, pick the Semester.
  3. Press Add Student.

Add many (Bulk Add)

  1. Bulk Add Students.
  2. Enter Start and End Register No (up to 500).
  3. Pick the Semester → Create Students. Existing numbers are skipped.
Rules
  • The semester must match the class (e.g. CSE Year 4 is in Semester 7 → choose 7).
  • New students start as Hosteller — change Day Scholars with Edit.
  • Student's first password = Register Number. Profile Status turns Completed after their first login.
Step 2

Edit, 7.5 scheme, delete, reports

Edit

Press Edit → change details, Email or Student Type → Update.

Student lost access to their email? Put the right email here, then they use Forgot Password.

7.5 Students

Tick every 7.5% scheme student of the class → Submit.

Unticked = not 7.5. They don't upload a hostel receipt.

No Due status

Press No Due on a row to see each office: Completed, Pending, Rejected or Incomplete.

Delete

Tick students (or Select All) → Delete → Yes.

Safe: deleted students go to Archived students and can be restored (Step 5).

Class report (PDF)

Open a class → Generate Report. Shows every student's status for each office and an overall status: Completed, Rejected, Pending or Incomplete.

Step 3

Settings and the request window

Unlock Promotion & Settings

  1. Sidebar → Promotion & Settings.
  2. Enter the Access Password (from the administrator) → Verify & Unlock.

It stays unlocked until you log out.

Open / close requests (No Due Access)

  1. Enable Access → choose 75 days or a custom end date and time → Enable Access.
  2. To close early: Disable Access.

It closes by itself at the end time. Students see Locked while it is closed.

Step 4

Promote students

Moves students to the next semester and gives them fresh No Due requests. Past clearance stays in History.

From → ToYearNeeds
Sem 1 → 2 · 3 → 4 · 5 → 6 · 7 → 8Same year—
Sem 2 → 3 · 4 → 5 · 6 → 7Year +1Semester 8 must be empty

Everyone (Semesters 1–7)

  1. Remove Semester 8 students first (Step 5).
  2. Check the green Ready for Promotion message.
  3. Promote Students → confirm.

One semester only

  1. Open Need Semester-Wise Promotion?.
  2. Pick the semester and the department (or all).
  3. Check the preview → Promote Selected Semester → Confirm & Promote.
Safe

The portal blocks any promotion that would mix semesters in a class or merge two batches, and refuses if the numbers changed since you opened the page. If something fails, nothing is changed.

Step 5

Undo, fixing classes, Semester 8 and archive

Undo the last promotion

Type UNDO → Undo this promotion. Students go back to their old semester.

Only the latest promotion, and only until a student sends a request for the new semester.

Fix a mixed class

If a class shows two semesters, press Set all to Semester X for the right one. It can be undone the same way.

Remove Semester 8 (final year)

Remove Semester 8 Students → Yes, Remove All. They move to Archived students.

Restore

At the bottom of the page tick archived students → Restore selected. Skipped if their Register / Roll No is now used or their class moved to another semester.

Step 6

Departments, problems, quick reference

Departments

  • Add: name (2–100) + code (2–20: A–Z, 0–9, - _ &), both unique.
  • Deactivate: hides it from lists; students stay.
  • Delete: only when it has no students.
  • Don't change the code of a department that has students.

Password Management (3rd tab)

  • See every office, department and Promotion password — press Show.
  • Change → new username / password → Save. Works immediately.
  • New department? Set its password here to create its login.
  • 5 wrong passwords lock a login for 15 minutes; saving a new password unlocks it.
